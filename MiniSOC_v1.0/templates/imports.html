Supported sources

Format is detected automatically

Sangfor AF / NGAF reports

Security log export (.xlsx or .csv) from IPS, WAF, Botnet, Anti-DoS. Report period and filters are read from the header rows; payloads are decoded for IOCs.

Generic tables

CSV / TSV / Excel with a header row — column names such as Time, Src IP, Dst IP, Dst Port, Action, Severity, Signature, User, Message are mapped automatically.

Windows events

Event Viewer “Save as XML”, wevtutil qe Security /f:xml, Event Viewer CSV or Get-WinEvent | Export-Csv.

Web & API

Apache / Nginx access logs, structured JSON application logs (login success/failure, password/role changes, API requests with bytes), API-gateway JSON.

Cloud, Linux & JSON

AWS CloudTrail, auth.log / secure / syslog, JSON arrays, JSON Lines, Winlogbeat / Elastic exports. Apps can also push logs to /api/ingest.

Sample files

The samples folder has synthetic Sangfor AF, Nginx access, JSON app/API, CloudTrail, Linux auth.log and Windows XML logs.
